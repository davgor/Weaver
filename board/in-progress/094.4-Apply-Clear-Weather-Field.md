# 094.4 — ApplyWeatherField / ClearWeatherField / GetWeatherAt

WeatherEngine applies sampled weather into WorldEngine overlays so subsequent WorldEngine cell reads reflect mutations; clearing restores base terrain reads.

**Parent:** `094-WeatherEngine-Climate-And-World-Mutations`. **Depends on:** `094.2`, `094.3`.

## Acceptance criteria

- [ ] `applyWeatherField({ dataRoot, worldId, day, bounds })` writes `weather.condition`, `weather.severity`, and optional `landTypeOverride` via WorldEngine public API
- [ ] Mutation rules unit-tested (e.g. storm/rain can flood grassland→swamp override; snow can chill grassland→tundra; drought can dry swamp→grassland)
- [ ] After apply, WorldEngine `getCell` returns mutated `landType` where rules apply
- [ ] `clearWeatherField` removes weather-owned overlays in bounds; WorldEngine reads revert to base landType
- [ ] `getWeatherAt` returns current condition/severity or clear when absent
