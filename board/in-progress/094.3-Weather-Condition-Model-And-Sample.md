# 094.3 — Weather condition model + seeded SampleWeather

Lock the weather condition enum and implement pure deterministic `sampleWeather` from world seed, campaign day, coordinates, and base landType. No WorldEngine I/O in this ticket.

**Parent:** `094-WeatherEngine-Climate-And-World-Mutations`. **Depends on:** `094.1`.

## Acceptance criteria

- [ ] `WeatherCondition` enum locked (at minimum: `clear`, `rain`, `storm`, `snow`, `fog`, `drought`, `heatwave`)
- [ ] `sampleWeather({ seed, day, x, y, landType })` returns `{ condition, severity }` deterministically for the same inputs
- [ ] Severity is a bounded number (e.g. 0–1 or 1–5) unit-tested
- [ ] Land-type bias documented in tests (e.g. desert prefers drought/heatwave; tundra prefers snow; ocean stays clear/storm-leaning)
