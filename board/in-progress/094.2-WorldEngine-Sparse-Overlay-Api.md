# 094.2 — WorldEngine public sparse-overlay API + effective landType merge

Expose WorldEngine’s existing overlays table through typed public APIs and merge reserved `landTypeOverride` into cell reads so peer engines (WeatherEngine) can mutate **results** without rewriting packed chunks.

**Parent:** `094-WeatherEngine-Climate-And-World-Mutations`. **Depends on:** WorldEngine store from `012`.

## Acceptance criteria

- [ ] Public APIs: `setSparseOverlay`, `getSparseOverlay`, `listSparseOverlays`, `clearSparseOverlays` (bounds and/or keyPrefix filters)
- [ ] `landTypeOverride` overlay values must be valid `LandType`; invalid values rejected
- [ ] `getCell` / `getWorldSpecific` / `getWorldWhole` return cells with `landType` overridden when overlay present; base chunk data unchanged
- [ ] Unit tests cover set/get/list/clear and effective read merge
- [ ] Admin `call` endpoints expose the new overlay APIs
