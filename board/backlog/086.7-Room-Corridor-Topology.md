# 086.7 — Room/corridor topology queries

Expose room and corridor graphs (rooms, connections, stairs) derived from generated layout metadata — not just raw cells.

**Parent:** `086-DungeonEngine-Instanced-Map-Store`. **Depends on:** `086.4`.

## Acceptance criteria

- [ ] APIs return room bounds/ids and corridor/stairs connections for a floor or dungeon
- [ ] Topology is deterministic from the same seed as cell generation
- [ ] Unit tests cover a known small fixture layout
