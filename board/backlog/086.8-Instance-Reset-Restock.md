# 086.8 — Instance reset / restock lifecycle

Support resetting or restocking an instanced dungeon without destroying its layout identity (for respawn / revisit flows).

**Parent:** `086-DungeonEngine-Instanced-Map-Store`. **Depends on:** `086.6`.

## Acceptance criteria

- [ ] Reset clears instance-scoped overlays/state while preserving geometry (or regenerates from seed as specified)
- [ ] Restock hooks are defined for later Enemy/Item consumers (even if stubbed)
- [ ] Unit tests cover reset idempotence
