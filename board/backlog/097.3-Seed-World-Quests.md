# 097.3 — Deterministic seedWorldQuests

Implement seeding that turns peer id pools + campaign/world seed into a stable set of world quest instances.

**Parent:** `097-QuestEngine-World-Quest-Seeding`. **Depends on:** `097.2`.

## Acceptance criteria

- [ ] `seedWorldQuests({ campaignId, worldId, seed, pools, counts? })` is deterministic for the same inputs
- [ ] Produces a mix of main/side instances with objectives pointing at ids from the supplied pools
- [ ] Idempotency policy documented and tested (e.g. re-seed same campaign replaces or no-ops — pick one)
- [ ] Unit tests do not require live World/NPC engines (pools are plain id lists)
