# EPIC: DMEngine guided character-creation orchestration

Port the AI-guided identity and opening-scene chat that closes out onboarding: **who / why / where / what**, then an opening scene the player confirms into play.

**Ported from:** `board/done/026-guided-character-creation.md`, `072-guided-conversation-generate-reply.md` through `077-enter-world-refreshdetail-wiring.md`, `163-identity-interview-sequential-foundations.md`, `170-guided-identity-why-advance-loop.md`, `172-guided-identity-what-advance-loop.md`.

**Depends on:** `029-CharacterEngine-Race-And-Background-Selection`, `026-CharacterEngine-Archetypes-And-Starting-Loadouts`, `030-CharacterEngine-Companions-And-Inactive-Proxy` (identity chat is grounded in all of these already being chosen), `063-NarrationEngine-Scene-Social-Split-And-Streaming` (the invention+validation engine this chat calls).

**LLM boundary:** the identity chat and opening scene are invented prose, so — same rule as `052`/`060` — **NarrationEngine** invents and validates each reply/scene against the character's actual race/background/gear/companion facts; **DMEngine only orchestrates** the phase sequence (which foundation is next, when the transcript is long enough to advance, when to present the opening scene for confirmation). DMEngine does not call LLMEngine directly for this chat's content.

## Acceptance criteria

- [x] Guided identity walks the four foundations (who / why / where / what) as a sequential chat; DMEngine drives phase sequencing while NarrationEngine generates each reply, grounded in the character's already-chosen race/background/gear/companion and validated against those facts
- [x] Character's `guidedCreationPhase`-equivalent state persists so the flow can be resumed if the app closes mid-onboarding
- [x] Opening scene is generated by NarrationEngine from the completed identity, presented for confirmation, and only "enters the world" (unlocks play) after explicit confirmation
- [x] No mechanical stats are decided by this chat — it produces flavor/identity text only; anything mechanical routes through CharacterEngine APIs
- [x] This package's consumption of `063`'s generation API and of `029`/`026`/`030`'s CharacterEngine APIs is each covered by `*.contract.test.ts` here against their real published APIs
